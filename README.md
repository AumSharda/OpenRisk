# OpenRisk

**Grow with clarity. Not guesswork.**

OpenRisk is a free, browser-based educational prototype that helps early-stage technology founders explore business risk, simulate growth scenarios, and identify when it may be useful to consult qualified professionals.

## Try it

Open `index.html` locally in a browser, or enable GitHub Pages in repository **Settings → Pages → Deploy from a branch → main / (root)**. Once deployed, the public link will usually be `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

## What it does

- Founder risk assessment and dashboard
- Six predefined growth simulations
- Rules-based guided question assistant (not a generative AI chatbot)
- Browser-local action plan and CSV export

## Privacy and limitations

This version is a static, client-side prototype. It has no backend, login, paid API, or server-side storage. Assessment state is stored in your browser using localStorage. Anyone with access to the same browser profile may be able to view locally saved information; avoid entering confidential information on shared devices.

OpenRisk provides educational information only, **not legal, financial, tax, insurance, cybersecurity, or other professional advice**. Its rules and scenarios are illustrative and have not been independently validated. It does not determine compliance, certify safety, or establish whether professional services are required. Consult qualified professionals for consequential decisions.
